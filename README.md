# 📝 Pokédex JS

A Pokédex application developed with JavaScript, consuming data from the PokéAPI to display Pokémon information in a dynamic and interactive interface.
Aplicação de Pokédex desenvolvida com JavaScript, consumindo dados da PokéAPI para exibir informações dos Pokémon de forma dinâmica e interativa.

## 📂 Project Structure / Estrutura do Projeto

The project is organized to separate the interface, styles, and application logic.
O projeto é organizado para separar interface, estilos e lógica da aplicação.

```text
├── assets/
│   ├── css/        # Stylesheets / Folhas de estilo
│   ├── images/     # Images and icons / Imagens e ícones
│   └── js/         # Application logic and API integration / Lógica da aplicação e integração com a API
├── index.html      # Application entry point / Ponto de entrada da aplicação
└── README.md
```

## 🛠️ How to Run / Como Executar

Clone the repository. / Clone o repositório.

```bash
git clone https://github.com/Larissangatto/pokedex-js.git
```

Access the project folder. / Acesse a pasta do projeto.

```bash
cd pokedex-js
```

Open the `index.html` file in your browser or use an extension such as Live Server.
Abra o arquivo `index.html` no navegador ou utilize uma extensão como o Live Server.

## 📖 Features / Funcionalidades

* Pokémon listing with data fetched from the PokéAPI. / Listagem de Pokémon consumindo dados da PokéAPI.
* Dynamic rendering using JavaScript. / Renderização dinâmica utilizando JavaScript.
* Pokémon details such as name, number, type, and image. / Exibição de informações como nome, número, tipo e imagem.
* Responsive layout for different screen sizes. / Layout responsivo para diferentes tamanhos de tela.

## 🎯 Project Goal / Objetivo do Projeto

The main goal of this project was to practice JavaScript fundamentals, including DOM manipulation, API consumption, asynchronous requests, object-oriented programming concepts, and dynamic rendering. The interface will continue to improve as new features are added, since the main focus of this version was the application logic.

O principal objetivo deste projeto foi praticar os fundamentos de JavaScript, incluindo manipulação do DOM, consumo de APIs, requisições assíncronas, conceitos de orientação a objetos e renderização dinâmica. A interface continuará sendo aprimorada à medida que novas funcionalidades forem adicionadas, já que o foco desta versão foi a lógica da aplicação.
